# Flappy Bird

A small single-file Flappy Bird clone built with HTML, CSS, and JavaScript.

Play the game in your browser — no build tools required.

## Files

- `Flappy Bird.html` — the complete game. Open this file in a browser to play.

## How to play

- Tap, click, or press Space (or Arrow Up) to flap the bird.
- Pass through gaps in the pipes to score points.
- The game ends when the bird hits a pipe or the ground.

## Run locally

1. Download or clone this repository:

   git clone https://github.com/ryzzrwitakad/flappy-bird.git

2. Open `Flappy Bird.html` in your browser.

Optional: To serve the game over HTTP (useful for mobile or when testing local storage):

- Python 3:

  python -m http.server

- Then open http://localhost:8000 and click `Flappy Bird.html`.

## Hosting

You can host this repository with GitHub Pages to make the game playable from a URL. In the repository settings, enable GitHub Pages for the `main` branch and root (/) and your site will be available at `https://<your-username>.github.io/flappy-bird/`.
